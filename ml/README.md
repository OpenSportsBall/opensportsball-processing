# ml

Labeling tools, detector fine-tuning and evaluation for ball and player
detection at youth-field distances. License: **AGPL-3.0-only**.

Datasets and weights never go in git (`ml/data/`, `ml/runs/`, `*.pt` are
ignored). Footage shows minors: keep it private and consented. Check each
public dataset's license (SoccerNet included) before training on it, and
record which datasets a released model was trained on.
